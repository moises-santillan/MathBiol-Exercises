# 13. Competitive Lotka-Volterra Model

The `Python` script `ch13.py` complements chapter 13 of the book, in which the competitive Lotka-Volterra model is analyzed. To simplify the analysis, we utilize a non-dimensionalized version of the equations, which reduces the parameter space while preserving the essential dynamics:

$$
\begin{align}
\frac{dn_1}{d\tau} &= n_1(1 - n_1 - a_{12} n_2), \\
\frac{dn_2}{d\tau} &= \rho n_2(1 - n_2 - a_{21} n_1),
\end{align}
$$

where $n_1$ and $n_2$ represent normalized population densities, $a_{12}$ and $a_{21}$ are the competition coefficients, and $\rho$ is the relative intrinsic growth rate.

### Fixed Points and Existence
The system yields four biologically relevant steady states:
1.  **$E_1 = (0,0)$**: Trivial equilibrium (extinction of both species).
2.  **$E_2 = (1,0)$**: Exclusion of species 2; species 1 reaches its carrying capacity.
3.  **$E_3 = (0,1)$**: Exclusion of species 1; species 2 reaches its carrying capacity.
4.  **$E_4 = \left(\frac{1-a_{12}}{1-a_{12}a_{21}}, \frac{1-a_{21}}{1-a_{12}a_{21}}\right)$**: The coexistence equilibrium.

Notably, $E_4$ is located within the first quadrant (where $n_1, n_2 > 0$) only if $a_{12}, a_{21} < 1$ or $a_{12}, a_{21} > 1$.

### Stability and Bifurcation Analysis
The stability of these steady states is dictated by the competition coefficients $a_{12}$ and $a_{21}$. A rich set of dynamics emerges as these parameters cross the critical threshold of $1$. Because this is a two-dimensional system governed by the simultaneous tuning of two parameters, traditional one-dimensional bifurcation diagrams are insufficient.

To explore this parameter space, the accompanying `Python` script (`ch13.py`) generates an interactive phase plane plot. This tool visualizes:
* The position of steady states.
* The system's stability via quiver plots (vector fields).

By varying the bifurcation parameters, we can observe the transcritical bifurcations: when a parameter $a_{ij}$ reaches $1$, the coexistence point $E_4$ collides and merges with one of the axial equilibria ($E_2$ or $E_3$), exchanging stability.
